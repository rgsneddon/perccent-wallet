Install notes

  • Windows: Verify SHA-256 before installing. Windows SmartScreen may ask you to confirm.
  • Android: Requires Android 6.0+ (API 23). Camera permission is requested only when you scan a PERC QR code.
  • iOS: Requires iOS 13+. v1.1.6 IPA is Apple Development–signed (team SFCBP95595, Bundle ID perccent-wallet). Password login and optional Face ID / Touch ID biometric vault enrollment are supported; enroll after login when prompted.
  • macOS: Requires macOS 10.15+. v1.1.6 zip contains MY PERC.app (universal, Bundle ID perccent-wallet, team SFCBP95595). Development-signed; if Gatekeeper blocks, right-click the app and choose Open.
  • Integrity: Every package ships with SHA-256 and SHA-512 checksum sidecars. Verify with CHECKSUMS.sha256 or checksums.json.
  • Full suite: For Evolve scenario analysis and governance tools, see Evolve Chronoflux.
