Install notes

  • Windows: Verify SHA-256 before installing. Windows SmartScreen may ask you to confirm. Current installer is still v1.1.5.
  • Android: Requires Android 6.0+ (API 23). Camera permission is requested only when you scan a PERC QR code. Current installer is still v1.1.5.
  • iOS: Requires iOS 13+. v1.1.6 IPA is Apple Development–signed (team SFCBP95595). Password login works; optional biometric vault enrollment is Android-only. Full automatic provisioning needs a registered device on the team for Xcode archive export.
  • Integrity: iOS v1.1.6 ships with SHA-256/SHA-512 sidecars. Verify with IPA .sha256 or checksums.json.
  • Full suite: For Evolve scenario analysis and governance tools, see Evolve Chronoflux.
